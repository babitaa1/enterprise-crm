# Enterprise CRM System

## Project Description

Enterprise CRM System is a web-based Customer Relationship Management application developed to manage customers, leads, deals, and activities in one place.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- REST APIs

## Main Features

- User registration and login
- Admin and user roles
- Customer management
- Lead management
- Deal management
- Activity management
- Dashboard
- MongoDB database integration

## How to Run the Project

### Start Backend

```bash
cd backend
node server.js
